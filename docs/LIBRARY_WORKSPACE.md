# 书目信息自动补全与编辑项目

导入时自动从 PDF 首页识别 DOI，通过 Crossref 正式记录补齐标题、所有作者、期刊、年份、卷期和出版日期。标题查询只接受可靠的唯一近似匹配。导入窗口显示“已核对：Crossref / DOI”等来源；失败或不可靠匹配会提示保留手工填写。不需要安装或运行 Ollama，不上传 PDF 或正文。

现有文献点击文库顶部“补全”，或编辑窗口里的“自动补全”。补全会校正基本书目信息，IF、自定义项目和其他手工内容保留。单篇编辑中补全后点击保存。

编辑窗口点击“添加项目”，输入“中文标题”等名称并填写内容，保存后显示在卡片上。项目定义和移除设置对整本文库生效，每篇文献的值分别保存。项目名称可修改；移除只隐藏、保留原值，可在“恢复已移除项目”中恢复。标题是文献身份的必填项。

# 文库界面与概览编辑

文献卡片的期刊名称下显示出版日期、卷期、页码与 DOI。点击 IF 修改影响因子，留空代表未知；铅笔图标打开完整元数据编辑。手工填写的 IF 不会被元数据补全或模型推测覆盖。

标签在每篇文献卡片底部：点击“添加标签”，搜索或输入新名称，回车或点击“新建”加入选择，可同时勾选多个，最后点击“应用”。标签上的 × 只移除这篇文献的关联。列表上方可按标签筛选；其他分类中已使用的标签也能在添加面板中找到。

右侧图标依次是打开阅读、文档处理、定位 PDF、补充材料和文献信息编辑。右端时钟显示简短时长，点击再看阅读时间详情。补充材料和原 PDF 继续保存在文献目录中。

“我的文献概览”用于自己的理解，可编辑文献概览、团队简介和摘要，也可添加、重命名和删除栏目。点击铅笔编辑，点击加号添加，修改后保存。小圆点表示尚有修改，勾号表示已保存，历史图标用于查看和恢复旧版本。

“AI 概览”的每个栏目对应实际保存的报告标题，不限制为固定类别。点击加号添加“重点”等栏目，填写标题和正文后保存；新栏目会按顺序出现在标签页中。点击铅笔可修改选中栏目，左右箭头可调整顺序，垃圾桶删除选中栏目。正文支持 Markdown，证据页码按原样保留。

文档图标打开完整读书报告及历史版本。在概览中保存会同步报告，在完整报告或关联笔记中修改报告并保存也会更新概览。切换文献或收起编辑时草稿保留，已保存版本始终从本地读取；生成新版本才请求所选模型。

阅读界面保留单栏放大 PDF、顶部进度折叠、连续高亮，以及实时翻译、笔记和文献概览三个常用侧栏入口。
