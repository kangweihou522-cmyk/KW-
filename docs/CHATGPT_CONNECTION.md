# 网页聊天与工作站自动连接

PaperDesk 本身不必使用 Codex。PDF 阅读、高亮、批注、笔记、已有报告和离线英中翻译不依赖它。

| 方式 | 能做什么 | 条件与限制 |
| --- | --- | --- |
| 打开 ChatGPT 网页 | 用原有 Google 等登录方式聊天、写作、分析；用户自行提交材料 | 不需要 Codex 授权；网页账户自己的权限、额度和验证要求仍适用，不会自动读取本地文献 |
| 官方 Codex 账户连接 | 工作站提取登记文献文字，自动生成报告或回答文献问题 | 需要单独完成官方授权，并有服务端确认的套餐内额度；可能要求手机号，网页已登录不保证授权成功 |
| OpenAI API | 程序通过 API 使用模型 | Plus/普通账户不包含免费 API；本项目没有配置或自动使用此付费通道 |

ChatGPT 网页会话和 Codex OAuth 是不同的客户端与授权流程。工作站打开的是官方客户端返回的授权页，手机号要求由服务方返回。账户权限、验证规则和安全检查可能不同，不能仅凭网页可登录断言具体触发原因，也不能在本地代码中取消它。浏览器授权与设备码都要求手机号时，应联系 OpenAI 支持确认自己的可用验证方式；继续重试不能保证解决。

官方说明：[Codex 认证](https://developers.openai.com/codex/auth)、[OpenAI 支持](https://help.openai.com/)。这些链接用于说明和咨询，不会自动提交论文或账户资料。

工作站不会复制浏览器 Cookie、导入网页会话凭据或把网页登录当作免费 API。只使用官方服务明确确认可用的套餐内 Codex 额度；确认失败或额度不足就停止，不购买额度或转用付费信用。

若网页 Google 登录正常，但两种 Codex 授权都要求手机号，该账户的自动 ChatGPT 报告/问答连接仍未解决。网页操作和手动回填只是独立可用入口，不作为自动连接已经完成的证明。已有本地报告继续读取和编辑，不再请求模型。
