# 0.6.4 精确划词与附件定位

- 划词只显示当前选中的词、短语或句子；整段缓存作为默认折叠的上下文参考。短词不再受旧的段落匹配长度门槛影响，按文献及上下文分别缓存。
- 全文预翻按句子保存，完整句子可直接复用；已有段落缓存继续保留，首次遇到新的局部选区才单独推理。
- 就绪检查不再静默关闭自动划词翻译开关；意外断开的本机推理连接会自动恢复一次；主动取消的旧选区不重试、不重启共享模型，也不覆盖新选区。恢复不会重新下载模型。
- 文库卡片中的自定义字段只展示填写的内容，字段名称保留在编辑器内。
- 补充材料点击文件名打开文件，旁边的文件夹图标打开所在文件夹并定位该附件。
- 更新仍使用桌面 PaperDesk - Update 或原 PowerShell 命令，保留文库、笔记、批注、模型及已有翻译缓存。

# 0.6.3 阅读缓存与一键处理

- 文库新增一键处理：本地解析一次、核对出版记录、本地通用模型生成概览、Hy-MT2 后台全文翻译。阶段进度可查看，暂停/继续/停止保留结果，重复处理复用缓存并保留已有概览与手工报告。
- 全文与划词共用本地翻译记忆，统一 PDF 换行、断词和空白；完整句段可供后续较小划选复用，清楚标注所在句段范围。缓存区分语言、模型和术语版本，旧划词缓存仍可读取。
- 阅读时可在空闲后预翻下一页，可在翻译设置关闭；推理按小段排队，划词优先于等待中的后台任务。
- 文献信息编辑新增本地分析：使用已配置的本地通用模型提取首页中有文字依据的候选信息，保存前仍可修改。核心书目信息仍优先核对 DOI 出版记录。
- 笔记保存后默认显示标签和正文预览，编辑时才显示工具栏/保存；取消顶部摘录与定位/笔记抽屉。保留原笔记、PDF 关联和报告版本。
- 继续通过桌面 PaperDesk - Update 或原 PowerShell 更新命令安装；保留文库、笔记、批注和已下载模型。

# PaperDesk 0.6.2：正式书目信息补全与自定义项目

修复元数据请求误走通用本地网络限制、PDF 中的错误作者及截断标题不被正式记录纠正的问题。不需要 Ollama 或其他模型。

- 导入时本地读取 PDF 首页 DOI，再查询 Crossref 正式记录，填入完整标题、全部作者、期刊、年份、卷期、出版日期、DOI。优先精确 DOI；仅有标题时要求高相似且唯一的结果，匹配不可靠就保留待填写。
- PDF 出版社信息不当作作者，文件创建时间不当作出版年份，摘要主题不当作期刊。只有 DOI 或标题用于查询，PDF 与正文不上传。
- 正式记录可以纠正自动识别的错误；导入窗口中已手工修改的项目保留。完成识别后才可确认导入，窗口显示核对来源或失败原因。
- 现有文献在文库顶部点击“补全”，或在单篇编辑窗口点击“自动补全”。并发最多三篇，同一查询短时间内复用结果。
- 文献编辑支持添加、重命名、移除和恢复项目。项目全库共用，内容按文献分别保存；添加“中文标题”等项目后，填写内容直接显示在文献卡片。隐藏 URL 等项目保留原值，恢复后可继续编辑。
- 自定义项目及内容写入本地数据库并随文库备份保留。沿用 0.6.1 翻译修复和原来的桌面自动更新入口。

保存退出后点击桌面 **PaperDesk - Update** 更新到 0.6.2；不需要手动下载更新包。已有文献点击顶部“补全”一次，新导入文献自动识别。

正式登记记录仍可能缺项，扫描件也可能读不到 DOI；软件不会用模型猜填，不承诺任意 PDF 都能完全自动识别。缺失项可手工填写。
