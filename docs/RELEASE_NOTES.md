# PaperDesk 0.4.1

划词翻译现在可以独立于 ChatGPT/Codex 登录：首次下载约 68 MB 的英中专用语言包后，选中文字就会在最右侧栏自动显示译文。翻译使用本机 CPU，不需要 Ollama、API 密钥、海外手机号或在线额度；结果本地缓存，旧选区自动取消，不再逐次确认。当前支持英语 → 中文，专业术语与结论仍需对照原文。

- 原有文献、笔记、附件、批注和可选本地大模型保留。语言包放在独立的 models/translation 目录，更新程序不重复下载已安装语言包。
- 更新包自带独立 Python 和专用翻译运行组件，无需用户安装 Python。组件、语言包均按锁定哈希校验，保留各自许可及 OPUS-MT 作者署名。
- 修正 PDF 换行、分词符号残留及部分常见科研术语；保留数字、段落和长输入尾部。模型仍是通用机器翻译，有限术语校正不能保证全部科研译文准确。
- 标题栏显示版本；顶部新增 ChatGPT 网页入口，可继续使用原有 Google 登录在官网聊天、写作和分析。网页入口不会自动读取本地文件。
- 自动报告和问答仍采用可选的官方 Codex 授权；网页登录可用不保证 Codex 免手机号，该限制仍未解决。Plus/普通账户不附带免费 API，工作站不购买额度或转用付费 API。已保存报告直接在本地阅读编辑。
- 连续高亮、颜色选择、撤销重做、批注定位及独立批注 PDF 保存继续保留。

已有安装请先关闭 PaperDesk，使用原 `D:\PaperDesk\tools\Update-PaperDesk.ps1` 对照本次 Windows ZIP 的实际 SHA256 更新。打开 PDF 的翻译栏，点击“下载并启用英中翻译”一次，此后划选自动显示；无需重装或重新下载 Ollama 模型。

验证：生产构建及 246 项回归通过；真实 Linux CPU 模型测试覆盖统计片段、长文本、缓存和取消。短句约 0.14–0.36 秒、初始化约 0.43 秒，仅代表开发机。发布流程先在标准免费 Windows runner 用自带运行组件执行真实模型测试，通过后才发布。你的 Windows 11 上的具体速度、科研质量和快捷键仍需本机验收。所有 CI 使用公开仓库标准免费 runner，没有付费 API 或付费 runner。
