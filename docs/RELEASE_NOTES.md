# PaperDesk 0.6.0：文库界面与可编辑概览

按确认的界面方案重排主文库。中间集中展示文献信息，右侧主要保留个人概览与 AI 概览；自定义栏目保存后能立即成为独立标签页，并同步到完整报告。

- 文献卡片显示标题、作者、突出显示的期刊、卷期、页码或文章编号、出版日期、DOI。更新时间缩小；移除卡片中的文件路径和阅读热力。
- IF 可直接点击填写、修改或清空，不推测缺失数值。元数据编辑入口保留；Crossref/OpenAlex、EndNote XML/RIS 可带入卷期、页码和日期。
- 每篇文献可以新建、搜索和多选标签；标签旁可直接移除，列表顶部可按标签筛选。标签和 IF 写入本地 SQLite，重开与备份保留。
- 右侧阅读、文档处理、定位 PDF、补充材料和编辑入口收为图标栏。阅读时间收在同一栏，点击再看详情；移除常驻的期刊会议块和年度指标块。
- 我的文献概览保留团队简介、摘要及自定义栏目；可增删标题和正文，保存标识缩成小图标，历史版本收进菜单。
- AI 概览不再将未知标题合并到默认栏目。可直接添加“重点”等栏目、修改内容、删除、调整顺序；也可从完整报告编辑，双方保存后同步显示，历史版本继续保留。
- 修复无宽度记录时误取最小值的问题；适配最小窗口尺寸，保留可拖动的分栏。
- 沿用大 PDF 阅读、顶部进度折叠、翻译/笔记/概览侧栏、连续高亮和原 PDF 保护。翻译、报告渠道与本地数据格式兼容此前版本。

已有 0.5.2 安装：保存并退出 PaperDesk，点击桌面 **PaperDesk - Update**，或运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'D:\PaperDesk\tools\Update-PaperDesk.ps1' -Root 'D:\PaperDesk'
```

更新器自动检查、下载、核验、备份并安装，保留文献、附件、笔记、批注、模型与缓存；无需手动下载更新包。更新连接继续支持 Windows 系统代理、重试和原生 curl 备用。
