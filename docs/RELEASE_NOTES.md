# PaperDesk 0.3.0

以已发布 0.2.1 为基础补齐网页报告与 PDF 阅读流程；不需要重新安装模型。

- 默认 ChatGPT 网页工作流，不自动启动 Ollama 或生成本地模型报告。Plus/普通账户不附带免费 API；用户自行附上论文，手动回填回答。
- 提示词要求 200–300 字梗概及七部分报告。草稿按文献保存，侧栏和弹窗共享；重复回填更新同一份本地笔记。报告可离线查看编辑，旧模型概览不会在网页模式覆盖回填摘要。
- 文库详情和右键菜单增加“打开 PDF 所在文件夹”，仅从登记附件定位。
- PDF 工具增加文字名称、撤销重做、批注列表搜索定位与未保存提示；高亮、文本批注保存到独立批注版，保留原始 PDF。
- **内嵌翻译仍为待验收功能**：已接入 MyMemory 公开免费渠道，用户确认后仅发送划选文字，译文显示在阅读器内并缓存。单次最多 500 UTF-8 字节，有服务方每日配额；不使用密钥或付费回退。此次云网络拦截真实接口，尚未验证实际可用性、速度和科研翻译质量，不能视为核心实时翻译已完成。不是“打开翻译网页”的替代入口。

已有安装请关闭 PaperDesk，下载 Windows ZIP，核对同一 Release 的 SHA256SUMS.txt，使用 `D:\PaperDesk\tools\Update-PaperDesk.ps1` 校验更新。更新工具先备份，保留独立存放的文献、笔记和附件。不要重复执行首次安装或模型下载。

本版在 Linux 通过生产构建、完整测试及真实 Electron 报告/PDF 批注流程验收。报告使用虚构回答；没有自动登录或调用 ChatGPT。Windows 资源管理器定位、快捷键、升级事务及真实在线翻译仍需本机验收。

Windows ZIP、对应源码 ZIP 和 SHA256SUMS.txt 由公开仓库标准免费 GitHub runner 生成。保留 AGPL-3.0-only 许可证和上游声明。
