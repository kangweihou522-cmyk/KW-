# PaperDesk 0.6.1：修复 Hy-MT2 下载与启用

修复高质量离线翻译反复显示“尚未安装或校验失败”的问题。此前同一条提示混合了未下载完整、安装登记缺失和运行组件启动失败；一次失败还可能使后续重试被旧状态阻挡。

- 下载使用桌面程序的网络组件，读取 Windows 系统/PAC 代理；继续核对官方 HTTPS 来源、固定版本、文件大小和 SHA256。
- 大模型下载支持重试、暂停和断点续传，临时文件保存在模型目录，下次从已有进度继续。
- 先检查本地模型：完整文件直接复用，登记文件缺失时重新校验并补齐；不会因一次启动失败强制重下约 1.13GB。
- 下载、校验、模型登记和运行组件启动分别显示状态与原因；磁盘/权限、连接、大小、摘要和运行错误不再统一显示成“重新下载”。
- 安装过程中划词请求等待同一任务；尚未启用时不会自动反复请求。启用成功后恢复自动翻译。
- 翻译栏显示连接/检查/下载/启动状态、实际 MB 进度、暂停按钮和检查详情。窗口切换后可重新读取后台进度。
- 沿用 0.6.0 文库界面、多标签、IF、概览编辑和自动更新方式，保留文献、附件、报告、批注、模型及缓存。

当前更新正在下载时，先让它完成。然后保存并退出 PaperDesk，再点击桌面 **PaperDesk - Update** 更新至 0.6.1。无需手动下载更新包。

更新后，在阅读器右侧选择 **高质量离线翻译 · Hy-MT2**，点击“检查并继续”或“检查并修复”。已有文件会先校验；只有确实缺失或损坏时才下载。

普通阅读与快速离线翻译可照常使用。Hy-MT2 无需 ChatGPT、Codex、API 密钥或账户授权。
