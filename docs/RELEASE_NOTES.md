# PaperDesk 0.5.0

阅读页改为紧凑顶部导航，默认放大PDF阅读区域，隐藏底部状态栏；阅读进度点开才显示。右侧以实时翻译、笔记、文献概览三个页签切换，保留宽度调节与折叠。译文优先显示，原文可折叠。

- 新增“我的文献概览”：团队简介、摘要与自定义栏目，标题和内容可增删编辑；本地SQLite保存，草稿恢复、历史版本、多窗口冲突保护。文库与阅读器展示同一份个人内容。
- 报告可直接手工填写或逐部分编辑，保存后无需AI重复阅读；再次生成保留旧版本，生成冲突的结果可从恢复副本找回。报告同步AI概览，个人概览不被AI覆盖。
- 新增Hy-MT2-1.8B Q4_K_M离线专用翻译与科研术语表。语言包约1.13GB，首次下载后本机使用；保留原约68MB快速英中引擎。
- ChatGPT改用官方开源本地应用套餐授权与Responses接口，不再运行或打包Codex。支持账户选择、可用模型目录、实际推理测试和安全令牌存储。
- 增加仅免费模型的OpenRouter报告渠道及可选自动备用。保留DeepL Free，增加带账户确认与本机字符上限的百度可选渠道。
- 连续高亮、撤销/重做、缩放、批注保存与重开状态经实际桌面检查；原PDF保留。原有文献、附件、笔记、批注及模型不随更新删除。

## 下载与更新

下载 `PaperDesk-0.5.0-Windows.zip` 和本发行版 `SHA256SUMS.txt`。关闭PaperDesk，用已有 `tools\Update-PaperDesk.ps1` 校验ZIP并备份后更新；已有安装不重新运行首次安装脚本。对应源代码随 `Source.zip` 提供。

高质量翻译模型需在新版右侧翻译设置中另行下载一次。ChatGPT账户需你本人通过浏览器授权；账户资格、手机号与套餐用量限制由OpenAI决定。DeepL、百度和OpenRouter需要你自行申请可选密钥。

## 验证范围

公开仓库标准Windows runner已完成真实Hy-MT2下载与推理、回归测试、实际Electron与打包后Windows程序的交互检查。具体记录见 `docs/VALIDATION.md` 及本次发行对应的Actions。用户账户授权、在线服务个人额度、RTX3060速度和真实科研准确率仍需在本人环境核实。
