# PaperDesk 0.4.0

优化文献阅读中的连续操作：浏览器授权后在工作站内处理文献，划选后自动在最右侧显示译文，高亮工具支持连续拖选。

- **ChatGPT 账户接入**：使用 OpenAI 官方 Codex 组件打开系统浏览器授权，无需安装或登录 Codex 桌面客户端。工作站自动提取当前 PDF 和已关联补充材料的文字，直接生成概览/七部分报告或回答文献问题，不再要求手动上传与回填。
- **本地保存**：报告自动保存到同一篇文献的本地笔记；再次阅读复用本地报告，重新生成需显式操作。生成期间的手工编辑不会被覆盖。问答与划词结果也复用本地缓存。
- **套餐内额度**：仅在官方服务确认有可用的套餐内 Codex 额度时提交任务。额度用尽或无法确认时停止，不购买额度、不改用付费 API、不凭信用余额自动继续；连接不等于免费无限 API，免费账户的可用性由服务端决定。
- **右侧自动翻译**：首次选择渠道并开启一次后，划选结束自动展开最右侧译文栏，取消逐次确认和浮层。支持流式译文、缓存、短暂防抖、取消旧请求，避免旧译文覆盖新选区。新配置的零宽度侧栏问题及旧版保存的零宽度已修复。
- **免费备用渠道**：可配置官方 DeepL API Free 密钥，由系统安全存储加密，仅调用 api-free.deepl.com。仍有服务方月度额度，额度满时不转付费 Pro。MyMemory 保留为低配额备用，不再是默认；没有承诺无限免费在线翻译。
- **连续高亮**：先点高亮工具，再连续划选即可变色；高亮状态保持，选颜色后继续。已有高亮不会拦截新的拖选。H 切换高亮、T 文本批注、Esc 退出、Ctrl+S 保存。保存到独立批注版，保留原 PDF。继续支持列表定位、编辑颜色、删除和撤销重做。

已有安装请关闭 PaperDesk，下载 Windows ZIP，对照同一 Release 的 SHA256SUMS.txt，用 `D:\PaperDesk\tools\Update-PaperDesk.ps1` 校验更新。保留已有文献、笔记、附件和批注；无需重新下载模型。

验证范围：Linux 生产构建与完整回归通过；真实 Electron 验证连续高亮、保存重开、自动右侧译文可见，以及报告保存/缓存。账户协议使用模拟响应测试，并实际验证官方组件的未登录状态、浏览器授权入口和只读线程创建。没有用用户账户完成授权或真实推理，Windows 浏览器授权回调、服务延迟与科研翻译/分析质量仍需本机验收。当前分析以提取文字为主，图像、复杂公式、扫描件遗漏会说明，不能宣称已可靠理解全部图表。
