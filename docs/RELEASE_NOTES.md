# 0.6.10 修复 Qwen 概括被误判为思考未结束

- 兼容 Qwen 仅返回思考结束标记 `</think>` 的响应。以最后一个结束标记分离正文，丢弃此前思考，避免完整概括被误拦截。
- 结束标记后为空、仍有未闭合思考、错误或不完整 JSON 时继续报错，不将思考或输入证据回显当作概括。
- 已用实际故障响应验证正文提取，增加结束标记、重试与桌面自动填充回归检查。概括仍不限字数，保留手工内容及摘要/中文标题的独立处理。

# 0.6.9 概括返回格式兼容与失败恢复

- 文献概括兼容 overview、summary、正文及中文概括字段、文字列表和分段结构；支持直接返回纯文本及带完整思考标签/代码围栏的正文。
- 首次无法读取正文时，自动切换为不要求 JSON 的纯文本请求，不再重复要求同一种失败格式。字数仍不设保存门槛。
- 错误信息、未知 JSON 对象、占位文字、不完整 JSON 和未结束思考不作为概括填入；原始响应及错误保存在本地 .reports/overview-recovery，便于恢复和排查，不含模型鉴权信息。
- 保留已有手工内容及摘要/中文标题的独立填充，使用桌面 PaperDesk - Update 更新。

# 0.6.8 概括不限字数，补齐摘要译文与中文标题

- 取消文献概括的字数保存门槛和凑字数重试。810 字、600 字或其他长度的有效概括都可直接填入空白“文献概览”，不再因未达 1000–1500 字而丢弃结果。
- 一键处理新增独立“摘要翻译”和“中文标题”步骤。摘要优先提取原 PDF 明确的摘要区域，必要时读取书目中的原文摘要；逐句复用全文译文缓存，缺失句子才翻译，再填入“我的文献概览→摘要”。未可靠识别时单独提示，不用引言或生成概括冒充摘要译文。
- 中文标题填入文献信息的“中文标题”自定义项目：已有项目直接复用，没有时自动创建，保持原标题。新增项目会即时显示在卡片和编辑窗口。
- 三项独立保存；概览模型失败不阻止摘要翻译或中文标题。已有手工内容、未保存草稿、自定义栏目和历史版本保留。再次一键处理可复用现有解析、报告及翻译缓存，继续补齐空项。
- 沿用桌面 PaperDesk - Update 更新入口，现有多分类、文献、笔记、批注及模型保留。

# 0.6.7 同一文献归入多个分类

- 文献卡片新增“管理分类”，右键菜单也可打开；可同时勾选多个分类，父子分类显示完整路径，便于区分同名分类。卡片直接显示当前所属分类。
- 拖动文献到新分类会增加归属，保留原有分类。取消勾选只移除对应归属；全部取消后进入“未分类”，不会删除文献、PDF、笔记或译文。
- 在另一个分类导入相同 PDF 时，复用原文献记录并加入所选分类，不生成重复 PDF 或文献副本。各分类共用同一个文献 ID、笔记、批注、概览和翻译缓存。
- 分类保存采用增减操作，保留其他窗口新加入的分类；父分类及“所有文献”的数量按文献去重。沿用现有数据库格式及桌面 PaperDesk - Update 更新入口。

# 0.6.6 自动填充、可调布局与 PDF 阅读

- 一键处理补齐“我的文献概览”的空白摘要及文献概览。概览依据全文证据报告生成，要求 1000–1500 字，输出不足或过长时纠正一次，仍不符合则显示失败，不填入短文冒充完成。复用已有证据报告缓存；保留手工内容、自定义或已删除栏目、草稿和历史版本。
- 文库左右栏移除 420/760 像素及导航 20% 的固定上限，拖动范围由窗口和其他栏的最小可用空间决定。阅读分栏移除 28%–72% 比例限制；右侧栏随窗口缩小适配，并支持双击恢复。
- “我的文献概览”和“AI 概览”底部增加上下拖动手柄，分别滚动并记住高度；支持方向键调整、双击恢复。在文库和原文件概览中均可使用。
- PDF 普通单击保留原生文字行为，双击选词、拖动选取；整段翻译改为右键“翻译此段”（也可 Alt+单击）。增加适配高 DPI 的画布像素预算，保留原 PDF 排版与字体渲染路径。
- 跨多句选区可精确拼接全文缓存中的对应句子，不重复推理；仅在完整覆盖所选原文时复用。不能可靠匹配的片段单独补译并缓存；长选区和后台句段不附带额外原文。旧段落保留为参考，不按中英字符比例截取译文。短词仍使用有界句子消歧，科研译文需对照原文核对。
- 继续通过桌面 PaperDesk - Update 自动更新，保留文献、笔记、批注、模型及全文翻译缓存。摘要和长篇概括使用已配置的本地通用模型，划词翻译继续使用专用翻译模型。

# 0.6.5 补充材料移除

- 每个补充材料新增移除按钮，传错后可直接取消与当前文献的关联，再重新添加。
- 移除不会删除原文件或本地副本，不影响主 PDF、笔记、已有报告和其他文献的附件；后续生成报告不再读取已移除的材料。
- 继续使用桌面 PaperDesk - Update 或原 PowerShell 命令更新。本版不调整翻译流程或缓存对齐方案。

# 0.6.4 精确划词与附件定位

- 划词只显示当前选中的词、短语或句子；整段缓存作为默认折叠的上下文参考。短词不再受旧的段落匹配长度门槛影响，按文献及上下文分别缓存。
- 全文预翻按句子保存，完整句子可直接复用；已有段落缓存继续保留，首次遇到新的局部选区才单独推理。
- 就绪检查不再静默关闭自动划词翻译开关；意外断开的本机推理连接会自动恢复一次；主动取消的旧选区不重试、不重启共享模型，也不覆盖新选区。恢复不会重新下载模型。
- 文库卡片中的自定义字段只展示填写的内容，字段名称保留在编辑器内。
- 补充材料点击文件名打开文件，旁边的文件夹图标打开所在文件夹并定位该附件。
- 更新仍使用桌面 PaperDesk - Update 或原 PowerShell 命令，保留文库、笔记、批注、模型及已有翻译缓存。

# 0.6.3 阅读缓存与一键处理

- 文库新增一键处理：本地解析一次、核对出版记录、本地通用模型生成概览、Hy-MT2 后台全文翻译。阶段进度可查看，暂停/继续/停止保留结果，重复处理复用缓存并保留已有概览与手工报告。
- 全文与划词共用本地翻译记忆，统一 PDF 换行、断词和空白；完整句段可供后续较小划选复用，清楚标注所在句段范围。缓存区分语言、模型和术语版本，旧划词缓存仍可读取。
- 阅读时可在空闲后预翻下一页，可在翻译设置关闭；推理按小段排队，划词优先于等待中的后台任务。
- 文献信息编辑新增本地分析：使用已配置的本地通用模型提取首页中有文字依据的候选信息，保存前仍可修改。核心书目信息仍优先核对 DOI 出版记录。
- 笔记保存后默认显示标签和正文预览，编辑时才显示工具栏/保存；取消顶部摘录与定位/笔记抽屉。保留原笔记、PDF 关联和报告版本。
- 继续通过桌面 PaperDesk - Update 或原 PowerShell 更新命令安装；保留文库、笔记、批注和已下载模型。

# PaperDesk 0.6.2：正式书目信息补全与自定义项目

修复元数据请求误走通用本地网络限制、PDF 中的错误作者及截断标题不被正式记录纠正的问题。不需要 Ollama 或其他模型。

- 导入时本地读取 PDF 首页 DOI，再查询 Crossref 正式记录，填入完整标题、全部作者、期刊、年份、卷期、出版日期、DOI。优先精确 DOI；仅有标题时要求高相似且唯一的结果，匹配不可靠就保留待填写。
- PDF 出版社信息不当作作者，文件创建时间不当作出版年份，摘要主题不当作期刊。只有 DOI 或标题用于查询，PDF 与正文不上传。
- 正式记录可以纠正自动识别的错误；导入窗口中已手工修改的项目保留。完成识别后才可确认导入，窗口显示核对来源或失败原因。
- 现有文献在文库顶部点击“补全”，或在单篇编辑窗口点击“自动补全”。并发最多三篇，同一查询短时间内复用结果。
- 文献编辑支持添加、重命名、移除和恢复项目。项目全库共用，内容按文献分别保存；添加“中文标题”等项目后，填写内容直接显示在文献卡片。隐藏 URL 等项目保留原值，恢复后可继续编辑。
- 自定义项目及内容写入本地数据库并随文库备份保留。沿用 0.6.1 翻译修复和原来的桌面自动更新入口。

保存退出后点击桌面 **PaperDesk - Update** 更新到 0.6.2；不需要手动下载更新包。已有文献点击顶部“补全”一次，新导入文献自动识别。

正式登记记录仍可能缺项，扫描件也可能读不到 DOI；软件不会用模型猜填，不承诺任意 PDF 都能完全自动识别。缺失项可手工填写。
